# Coador 0.1.0

Release date: 2026-09-17.

Coador builds a local, evidence-backed knowledge base for Android repositories.
Default scanning requires no Gradle, JDK, Android SDK, LLM or external service.

## Features

- 84 detectors across nine knowledge layers.
- Schema v3 profiles with source-line, file-level and Gradle-model evidence.
- CLI overview, section retrieval and lexical search.
- Six MCP tools and project resources over stdio.
- Inventory completeness, pagination, freshness checks and damaged-output recovery.
- Optional Gradle probing for trusted projects.
- No telemetry or automatic submission of repository data.

## Getting started

Install from the checkout using the [installation guide](../../README.md#installation).
Use the [local example](../../examples/README.md) without downloading an Android
project, or follow the [public-project recipes](../onboarding-recipes.md).
[MCP configuration](../mcp.md) covers Codex, Claude Code and other stdio clients.
Contributors can start with the [bounded contribution tasks](../contributor-tasks.md).

## Compatibility and limitations

Python 3.11 or newer is required. CI targets Linux on Python 3.11–3.13 and
Windows/macOS on Python 3.12. Network and real-project Gradle checks are opt-in.

Heuristic findings are observable signals, not compiled architectural truth.
Missing evidence does not prove absence. Gradle probing executes the target build
and may download dependencies; use it only on trusted repositories. MCP refresh
uses heuristic scanning.

Sanitization does not guarantee that a private project profile is safe to publish.
Review generated output before sharing it. See [SECURITY.md](../../SECURITY.md)
for the complete boundaries and [CHANGELOG.md](../../CHANGELOG.md) for release notes.
